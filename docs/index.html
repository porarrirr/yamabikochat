YamabikoChat

複数の AI プロバイダーを切り替えられる、BYOK（自分の API キー持ち込み）型チャットアプリです。

iOS 17+ Android BYOK Markdown / MathJax
GitHub サポート

主な機能

  • 1 対 1 チャット（OpenAI / Gemini / OpenRouter / Codex ほか）
  • デュアルモード（2 モデルの同時比較）
  • 自動会話（モデル A / B が交互に会話）
  • Markdown 表示（MathJax 数式対応）
  • 添付ファイル（画像 / PDF / テキスト、1 ファイル最大 10MB）
  • Share Extension（テキストや URL をアプリへ送る）
  • 音声入力（マイク + 音声認識）

課金について

アプリ内で AI の利用枠やサブスクリプションを販売しません。利用料金は、ユーザーが接続した各 プロバイダーの契約に従います。

English

YamabikoChat is a native chat client for iOS and Android. Connect your own API keys or OAuth accounts, compare two models side by side, or run auto conversations between models. The app stores conversations locally and sends prompts only to the provider you select.
