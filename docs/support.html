サポート

不具合報告・機能要望・利用に関する質問は GitHub Issues で受け付けています。

Issue を作成 既存の Issue 一覧

報告時に含めてほしい情報

  • アプリのバージョン（設定 → 診断ログに記録あり）
  • 端末モデルと OS バージョン
  • 使用しているプロバイダー名（API キー本体は送らないでください）
  • 再現手順と期待する動作
  • 可能なら設定画面の診断ログ（API キーやトークンを除いたもの）

よくある質問

メッセージを送れない

本アプリは BYOK です。設定で API キーまたは OAuth（Codex など）の接続が必要です。キー未設定のままでは送信できません。

料金はかかりますか？

アプリ自体は無料ですが、接続した各 AI プロバイダーの利用料金が発生する場合があります。プロバイダー側の契約をご確認ください。

データはどこに保存されますか？

会話履歴と設定は端末内に保存されます。プロンプトは送信時に選択したプロバイダーへ送られます。詳細は プライバシーポリシーを参照してください。

免責

本ページ、Issue への回答、診断ログの共有に関する案内は参考情報です。これらに基づく設定変更、データ送信、運用判断の結果について、開発者は責任を負いません。詳細は 利用規約を参照してください。
