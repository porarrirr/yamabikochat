日本語

YamabikoChat（以下「本アプリ」）は、ユーザー自身の API キーまたは OAuth アカウントを用いて第三者の AI サービスと通信する BYOK 型チャットクライアントです。

端末に保存する情報

  • 会話履歴、プロジェクト、各種設定
  • API キーおよび OAuth トークン（iOS Keychain / Android の安全な保存領域）
  • ユーザーが任意で保存・共有できる診断ログ

第三者へ送信する情報

  • メッセージ送信時、ユーザーが選択したプロバイダーへプロンプト、モデル設定、添付を送信します。
  • リモート MCP、検索、コード実行などのオプション機能は既定で無効です。有効化した場合、ユーザーが設定した HTTPS エンドポイントまたは選択プロバイダーへ関連情報が送信されます。
  • Share Extension は共有テキストまたは URL をアプリグループに保存し、本体アプリで下書き会話を開きます。

行わないこと

  • アプリ内での AI 利用枠・サブスクリプションの販売
  • App Tracking Transparency によるクロスアプリ追跡
  • 診断ログへの API キー、トークン、プロンプト全文の意図的な記録

権限

  • 写真: 会話への添付のための読み取り専用アクセス
  • マイク・音声認識: 音声入力（任意）のみ

免責（データ・セキュリティ）

  • 本アプリは端末内保存およびユーザー選択の送信先への通信を前提としますが、完全な安全性、漏えい防止、データ復旧を保証しません。
  • 会話履歴・設定・診断ログのバックアップ、削除、端末紛失時の対応はユーザーの責任です。
  • ユーザーが診断ログをコピー・共有した場合、その内容と共有先の管理はユーザーの責任です。
  • 接続先プロバイダー、カスタム API、リモート MCP 等の第三者によるデータ取扱いについて、開発者は管理・保証せず、それらのプライバシー慣行に関する責任を負いません。

本ポリシーはデータの取扱いを説明するものであり、本アプリの利用に関する責任制限は 利用規約に従います。

English (U.S.)

YamabikoChat is a bring-your-own-key (BYOK) chat client. This policy describes how the app handles information on your device.

Stored locally

  • Conversation history, projects, and app settings
  • API keys and OAuth tokens in the platform secure store
  • Optional diagnostic logs you can view, copy, share, or clear

Sent to third parties

  • When you send a message, your prompt, model settings, and attachments go only to the provider you selected (for example OpenAI, Google Gemini, OpenRouter, or a custom endpoint you configure).
  • Optional tools (remote MCP, search, code execution, and similar features) are off by default. When enabled, related requests are sent to the provider or HTTPS endpoint you configure.
  • The Share Extension stores shared text or a URL in the app group so the main app can open a draft conversation.

What we do not do

  • Sell subscriptions, tokens, or provider access inside the app
  • Use cross-app tracking via ATT
  • Record API keys, tokens, refresh tokens, or full prompts in diagnostic logs by design

Permissions

  • Photos: read-only access to attach recent images
  • Microphone and speech recognition: optional voice dictation only

Disclaimer (data and security)

  • The App is designed for on-device storage and user-selected destinations, but does not guarantee complete security, prevention of leaks, or data recovery.
  • You are responsible for backing up, deleting, and protecting conversation history, settings, and diagnostic logs, including if your device is lost.
  • If you copy or share diagnostic logs, you are responsible for their contents and recipients.
  • The developers do not control or guarantee how third-party providers, custom APIs, or remote MCP servers handle your data.

This policy explains data practices. Limitations of liability for use of the App are set out in the Terms of Use.

Español (España)

YamabikoChat (la «App») es un cliente de chat BYOK (bring your own key): usted conecta su propia cuenta o clave API de proveedores de IA de terceros. Esta política describe cómo la App trata la información en su dispositivo.

Datos almacenados localmente

  • Historial de conversaciones, proyectos y ajustes de la app
  • Claves API y tokens OAuth en el almacén seguro del sistema (Keychain / almacenamiento seguro)
  • Registros de diagnóstico opcionales que puede ver, copiar, compartir o borrar

Datos enviados a terceros

  • Al enviar un mensaje, el prompt, la configuración del modelo y los adjuntos se envían solo al proveedor que usted seleccione (por ejemplo OpenAI, Google Gemini, OpenRouter o un endpoint personalizado).
  • Las herramientas opcionales (MCP remoto, búsqueda, ejecución de código, etc.) están desactivadas por defecto. Si las activa, las solicitudes relacionadas se envían al proveedor o al endpoint HTTPS que configure.
  • La extensión Compartir guarda texto o una URL en el grupo de la app para abrir un borrador en la app principal.

Lo que no hacemos

  • Vender suscripciones, tokens o acceso a proveedores dentro de la app
  • Seguimiento entre apps mediante App Tracking Transparency
  • Registrar intencionadamente claves API, tokens o prompts completos en los registros de diagnóstico

Permisos

  • Fotos: acceso de solo lectura para adjuntar imágenes recientes
  • Micrófono y reconocimiento de voz: solo para dictado por voz (opcional)

Exención de responsabilidad (datos y seguridad)

  • La App está pensada para almacenamiento en el dispositivo y destinos elegidos por el usuario, pero no garantiza seguridad total, prevención de fugas ni recuperación de datos.
  • Usted es responsable de las copias de seguridad, la eliminación y la protección del historial, los ajustes y los registros de diagnóstico, incluso si pierde el dispositivo.
  • Si copia o comparte registros de diagnóstico, es responsable de su contenido y de los destinatarios.
  • Los desarrolladores no controlan ni garantizan cómo los proveedores externos, las API personalizadas o los servidores MCP remotos tratan sus datos.

Esta política describe las prácticas de datos. Las limitaciones de responsabilidad por el uso de la App figuran en los Términos de uso.

简体中文

YamabikoChat（「本应用」）是一款 BYOK（自带密钥）聊天客户端。您使用自己的 API 密钥或 OAuth 账户连接第三方 AI 服务。本政策说明应用如何在您的设备上处理信息。

本地存储的信息

  • 对话记录、项目和应用设置
  • API 密钥和 OAuth 令牌（存储于 iOS 钥匙串 / Android 安全存储区域）
  • 您可自行查看、复制、分享或清除的可选诊断日志

发送给第三方的信息

  • 发送消息时，您的提示词、模型设置和附件仅会发送到您为该对话选择的提供商（例如 OpenAI、Google Gemini、OpenRouter 或您配置的自定义 API 端点）。
  • 远程 MCP、搜索、代码执行等可选工具默认关闭。启用后，相关请求会发送到您配置的提供商或 HTTPS 端点。
  • 共享扩展将共享的文本或 URL 保存在应用组中，供主应用打开草稿对话。

我们不会做的事

  • 在应用内销售订阅、令牌或提供商访问权限
  • 通过 App Tracking Transparency 进行跨应用追踪
  • 在诊断日志中故意记录 API 密钥、令牌或完整提示词

权限

  • 照片：只读访问，用于将最近的照片附加到对话
  • 麦克风和语音识别：仅用于可选的语音听写输入

  • 本应用以设备本地存储和用户选择的传输目标为前提，但不保证绝对安全、防泄露或数据恢复。
  • 您须自行负责对话记录、设置和诊断日志的备份、删除与保护，包括设备丢失的情况。
  • 若您复制或分享诊断日志，须自行对其内容及接收方负责。
  • 开发者不控制也不保证第三方提供商、自定义 API 或远程 MCP 服务器如何处理您的数据。
