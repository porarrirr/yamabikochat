iOS版 GenUI

GenUIは、会話の中に計算フォーム、カード、表、グラフなどの操作できるUIを表示するローカルツールです。基本形式はSwiftUI、リッチ形式はアプリに同梱したJavaScript/CSSをWKWebViewで描画します。

概要と表示位置

genui ツールが成功し、結果がGenUI文書として検証されたときだけ、アシスタントのメッセージ内にキャンバスが表示されます。通常会話ではツールの実行順に応答文の前へ並び、デュアル会話では各モデル側のカード内に表示されます。実行中の活動表示は先に出ますが、文書が完成するまではキャンバスを描画しません。

モデルが genui を呼ぶ→文書を検証→SwiftUI または WKWebView で描画→アシスタント応答

ツールが提供される会話

プロバイダーがクライアントツールに対応し、通常またはデュアル会話のツール許可範囲にある場合に提供されます。Secret会話、auto会話、Fusionパネルでは使いません。Geminiにネイティブツールがある場合はそちらを優先します。

実行方式

Piの既存ツールレジストリ／ストリームを通します。Apple PCCでは再帰的なJSON Schemaを渡せないため、同じ文書をJSON文字列の document 引数で渡します。独自のプロバイダ通信経路は作りません。

2つの表示方式

文書のトップレベルで、components、ui、code のいずれか一つを選びます。最初の方式は定型的な計算・比較UI向け、後ろの2つはレイアウトや連動操作を構成するリッチ方式です。

基本形式（SwiftUI）

見出しの下に、主要な結果を置きます。入力があると「結果 / 条件」の切り替えが現れ、結果を見ながら条件を調整できます。条件表示中も先頭のKPIまたはカード要約は残ります。

リセット

入力がある文書はヘッダーに44ptタップ領域のリセットボタンを表示します。

式と値の差し込み

式は文字列の先頭に = を付けます。入力IDは数値変数として参照し、表示テキスト中の {{inputID}} は現在値に置き換わります。式で計算できない場合は値欄に — を表示します。

{"id":"monthly","kind":"metric","title":"月々の返済額",
 "value":"=round(payment(principal,rate,years))",
 "format":"currency","unit":"円"}

演算子: + - * / ^ と括弧。関数: min、max、abs、round、pow、payment(principal, annualPercent, years)。paymentの金利引数は年率%（例: 5 = 5%）です。任意コードや条件分岐は実行しません。

リッチ形式（UIツリー / コード）

ui は {type, props, children} の部品ツリーです。code は DIL.h(...) でノードを返すJavaScript関数本体で、JSXやimportは使いません。どちらも同じホワイトリスト部品を使い、部品間でローカル状態を共有できます。

const [count, setCount] = DIL.useState(0);
return DIL.h("button", {
  label: "回数を増やす",
  onClick: () => setCount(count + 1)
}, String(count));

JSONのUIツリーでは、最上位の state を初期状態にし、部品の bind でキーを結びます。イベントオブジェクトは setState / resetState またはユーザー起点のホスト操作を表します。DIL hooksは useState、useMemo、useCallback、useRef、useEffect、useId、useTheme、useBreakpoint です。

各部品を実際に描画したサンプル

下のカタログは、アプリに同梱されているGenUIランタイムとスタイルで各部品を描画します。入力、ボタン、カルーセルを操作できます。画像・動画はサンプルHTTPSリソースを読み込みます。

ブラウザで再現できるのはリッチUIのWeb表示部分です。MapKitシート、詳細シート、クリップボード、外部リンク、新しい会話ターンなどのホスト操作はiOSアプリ内でのみ動きます。端末やWKWebViewの差でネイティブ画面とピクセル単位では一致しません。

現行のリッチ文書validatorでは radio-group.options が許可されていないため、ギャラリーでは空のグループ枠を表示しています。選択肢付きのグループは現状の有効なGenUI文書から指定できません。
カタログに含まれていても、プロパティの意味がすべてWeb標準やChatGPT側の実装と同じとは限りません。selectはブラウザ/iOS相当、popoverは文書内配置など、このアプリの互換動作になります。

地図・外部操作

MapWidgetV2 の画面遷移

GenUI内にタイトル・説明・地点一覧→ユーザーが地図ボタンをタップ→ネイティブMapKitシート→必要なら地点カードからApple Mapsへ
  • points と任意の origin は緯度・経度が必須です（lat/lng または latitude/longitude）。住所文字列だけから座標検索はしません。
  • ネイティブ画面ではピン、グループ色、地点カード、任意の説明文を表示します。carousel: true は地点カードを横スクロールにします。
  • 実経路は show_route: true のときだけMapKitに依頼します。driving、walking、transitに対応し、経路取得中・成功・失敗を状態文で知らせます。
  • stop順の自動最適化は未対応です。時刻指定は2地点間だけで、arrive_by と depart_at は同時に使えません。

ホスト操作

copy、openUrl、issueNewTurn、openEntityDetail は明示的なユーザー操作からのみ実行します。新しい会話ターンはPiの通常経路に流します。URLは認証情報を含まないHTTPSのみ許可し、送信中の応答や入力欄の下書きがあると実行できない状態を案内します。

状態・保存と寿命

入力の反映

基本形式はSwiftUI内で即時計算し、モデルへ再問い合わせしません。リッチ形式もbindやDIL hooksで同じキャンバス内を更新します。明示的なFollowUp / issueNewTurnのみ新しい会話ターンになります。

保持範囲

成功した文書は既存のツール活動と選択された応答バリアントに保存します。入力状態は行表示の再利用中は保ちますが、会話を開き直した後は文書の初期値に戻ります。別のツール呼び出しは別状態です。

古いPiデータで成功結果がプロバイダートランスクリプトだけに保存されている場合も、ツール呼び出しIDと成功結果を照合し、検証できた文書のみ画面用ステップとして復元します。モデルやツールを再実行せず、エラー・不正JSON・孤立結果は表示しません。

表示上の制限とフォールバック

機能iOSでの扱い
モバイルレイアウト基本形式はコンパクト時の余白を詰め、チャート高160pt、入力操作の高さ44ptを維持。通常サイズではチャート高220pt。大きな文字にも折り返して対応。
リッチキャンバスコンパクト幅は最大400pt、regular幅は最大560pt。内容が上限を超えるとWKWebView内でスクロール。
画像・動画検索query文字列からの取得はしません。文書内resourcesまたはノードにHTTPS URL / 参照IDを明示します。解決できなければ「利用できません」表示。
リンク・引用・Entity外部バックエンドを自動照会しません。URLや引用テキストなどのresourceが無ければ未解決表示または無効ボタンになります。
AppBlock文書に含まれたinline node treeまたはクライアント関数のみ。bundle id / version / entrypoint名だけではChatGPTアプリ資産にアクセスしません。
CodeBlock表示と任意の編集のみ。外部コード実行やモデルプレビューは行いません。
ポップオーバー文書フロー内に展開。ポータル配置や衝突回避、side指定どおりの画面外位置調整はしません。
互換外コンテンツ未対応の部品/参照/表示データは、推測した内容の代わりに目に見えるUnavailable表示やステータスを出します。

スタイルはアプリ内CSSのティールアクセント、角丸カード、淡い背景が基本です。ダークモードでは背景色・文字色・境界色を切り替えます。リッチ文書で指定した各部品のサイズや見た目は尊重されます。

検証・安全性

GenUI文書は実行結果として採用する前に検証します。レンダラー選択、部品名、props、ID、式、データ範囲の不正はツールエラーになります。

リッチ文書の容量

ui / code形式は文書・コード容量、UIノード数・深さ、state / resources件数のアプリ独自固定上限なし。実際の容量は端末メモリ、JSONパーサー、JavaScript / WebKitに依存し、無制限動作やChatGPT内部仕様との一致は保証しません。

基本形式上限

inputs 24個、components 48個、table列12・行100、chart系列8・各100点、cards 24個。

URL / 通信

リモートJS、iframe、フォーム送信、任意ネット接続は無効。宣言済みHTTPSメディアホストだけを許可します。

生成コードの描画、effect、保存stateの復元だけではネイティブ操作や新しいモデルターンは始まりません。WebKitの信頼済みユーザー操作を検知し、1回の操作に対応するホスト動作だけを通します。
